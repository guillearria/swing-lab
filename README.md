# Swing Lab

An AI made stock predictions in public, before the outcomes were known, and every prediction is scored.

**[See the scoreboard](https://guillearria.github.io/swing-lab/)**

## What it found

The predictions did not beat the market. The test had a pass mark set in advance. It was checked once, on 2026-10-02, and it failed. New predictions have stopped. The open ones keep being scored as they finish, the last around January 2027.

## How it works

- Each prediction was saved before its result existed, so it cannot be edited afterwards.
- A plain program, not the AI, scores each one against a market benchmark.
- Every result stays in the record, good or bad.

## Not investment advice

This is a research log, not a recommendation service. The author may at times hold positions in securities mentioned.
